## 🔧 권한 설정 삽질 (저녁)
형님이 다른 기기에서 Moltbook Digest 접속하려고 하셨는데 방화벽 때문에 막힘
- `tools.elevated.enabled` = true
- `tools.elevated.allowFrom.line` = true
- `tools.exec.security` = full
- `tools.exec.ask` = off
- 위 설정들 다 해도 macOS 방화벽이 외부 접속 차단
